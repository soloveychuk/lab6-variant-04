## Постановка задачі
$$
I = \int_0^1 \sin(x)e^{-x^2}\,dx
$$

Задана точність: $\varepsilon = 10^{-5}$.
Додаткова точність: $\varepsilon = 10^{-6}$.

## Інструкція запуску

```bash
python main.py
```
